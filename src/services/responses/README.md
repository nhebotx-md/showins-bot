# Modul Respons Bot

Folder ini adalah titik pengembangan lokal untuk tampilan dan pembungkus respons Showins Bot.

| Berkas | Tanggung jawab |
|---|---|
| `branding.js` | Header teks, context preview, thumbnail, dan konfigurasi branding jujur. |
| `index.js` | Facade import stabil untuk router dan layanan lain. |

Tambahkan variasi respons baru sebagai modul terpisah pada folder ini dan ekspor melalui `index.js`. Jangan menyisipkan metadata forwarded, status verifikasi, kontak pihak ketiga, atau dokumen yang tidak sesuai dengan isi sebenarnya.
